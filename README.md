# Hangman Game 🎮

A simple text-based Hangman game developed using Python.

## 🎯 Features

- 5 predefined words
- Maximum 6 incorrect guesses
- Letter-by-letter guessing
- Random word selection
- Console-based gameplay

## 🛠️ Technologies Used

- Python
- Random module
- While loop
- If-else
- Strings
- Lists

## ▶️ How to Run

Run the `hangman.py` file using Python.
